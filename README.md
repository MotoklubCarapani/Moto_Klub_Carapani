# Мото клуб „ЧАРАПАНИ“
Мото клуб „ЧАРАПАНИ“ настао је 2006 године као локални moto клуб у Крушевцу са циљем да окупи све бајкере на једном месту.Како се клуб развијао и растао променио је име у Мото клуб „ЧАРАПАНИ-СРБИЈА“ и изашао из локалних граница тако да данас окупља чланове како у градовима Србије тако и ван земље са тежњом да се и дање шири.
